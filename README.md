# ☕ Grão de Café

Projeto web desenvolvido para praticar **HTML e CSS**, trabalhando com estrutura de páginas, estilização, imagens e organização de arquivos.

## 🎯 Objetivo

Construir uma página temática sobre café como exercício de desenvolvimento front-end e consolidar fundamentos de desenvolvimento web.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Git e GitHub

## 📁 Estrutura

- `index.html` — estrutura principal da página
- `css/` — estilos
- `img/` — recursos visuais

## 📚 Conceitos praticados

- Estrutura semântica em HTML
- Seletores e propriedades CSS
- Organização de arquivos
- Imagens e recursos externos
- Desenvolvimento de interfaces para Web
